UCI Student Performance data and dictionary: https://archive.ics.uci.edu/dataset/320/student+performance
Keras MNIST loader: https://keras.io/api/datasets/mnist/

The course feedback comments were authored for this class. They are demonstration data, not real survey responses.
Student Performance dataset: Paulo Cortez, UCI Machine Learning Repository, DOI 10.24432/C5TG7T, CC BY 4.0. Only the selected mathematics course fields are included.
MNIST: Yann LeCun, Corinna Cortes, Christopher Burges; source distributed through Keras.

Image subsets retain the source class labels. They were sampled with seed 42 and resized only where needed. Train and test sources are kept separate when provided by the source. These small subsets are for classroom study. Keep notices with copies; the public GitHub app needs trained models, not the full image dataset.
VADER lexicon: C. J. Hutto and Eric Gilbert, 2014, distributed through NLTK data. NLTK data source: https://github.com/nltk/nltk_data
